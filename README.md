# E-commerce Projects 03–04 — PostgreSQL version

The original Project 03 code used MySQL. This package provides a PostgreSQL-compatible Project 03 foundation and the complete Project 04 SQL workflow.

## Run order

1. Open `Project03_PostgreSQL`.
2. Copy `.env.example` to `.env` and enter PostgreSQL credentials.
3. Install `requirements.txt`.
4. Run `python genData_postgresql.py`.
5. Open `Project04_SQL` and run SQL files `00` through `07` in order.

See each folder's README for details.
